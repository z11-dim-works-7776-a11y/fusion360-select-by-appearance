# 外観名で選択 (Select by Appearance)

Autodesk Fusion 向けの外観（色）ベース フェース一括選択アドインです。  
モデル内で使用されている外観を自動認識し、チェックボックスで選ぶだけで該当するすべてのフェースを瞬時に選択状態にします。  
CAMのツールパス設定時の面選択や、選択セット（Selection Set）の作成など、製造・モデリング作業を大幅に効率化します。

---

## 🌟 主な機能

- **🎨 外観（色）の自動認識＆一覧化**
  - デザイン全体を自動走査し、実際に使用されている外観名を抽出して一覧表示します。手動での名前入力は一切不要です。
- **☑️ 直感的なチェックボックスUI**
  - 起動するとチェックボックスが縦に一覧表示され、ワンクリックで選択できます。複数色の同時選択にも対応しています。
- **👀 リアルタイム ライブプレビュー**
  - ダイアログ上でチェックボックスをクリックした瞬間に、該当フェースが画面上で青くハイライト表示されます。どの面が選択されるかを目視確認しながら作業できます。
- **🧩 コンポーネント・ボディ・フェースの全階層対応**
  - フェース単位での色分けはもちろん、ボディ単位や親コンポーネントに割り当てられた外観の継承関係も正確に判定します。
- **🛠️ ソリッドツールバーへの統合**
  - 「ソリッド」タブの「修正」パネル内に専用アイコン付きで登録され、いつでも素早く起動できます。

---

## 💻 動作環境

- **対応CAD**: Autodesk Fusion (Windows / macOS)
- **言語**: Python 3 (Fusion 内蔵ランタイム)

---

## 🚀 インストール方法

1. 本リポジトリをダウンロード（ZIP）またはクローンします。
2. フォルダ名を **`外観名で選択`** とします。
3. Fusion のアドインフォルダに配置します：
   - **Windows**:
     ```text
     %APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\外観名で選択
     ```
   - **macOS**:
     ```text
     ~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/外観名で選択
     ```
4. Fusion を起動（または再起動）します。
5. **ユーティリティ > アドイン > スクリプトとアドイン**（Shift + S）を開き、「アドイン」タブから **外観名で選択** を選択して「実行」をクリックします。（「起動時に実行」にチェックを入れておくと便利です）
6. 「ソリッド」タブ >「修正」パネルの下部に「外観名で選択」ボタンが追加されます。

---

## 📖 使い方

1. 事前にモデルのコンポーネント、ボディ、またはフェースに任意の外観（色）を適用しておきます。
2. ソリッドタブの「修正」パネルから「外観名で選択」をクリックします。
3. ダイアログにモデル内で使われている外観一覧が表示されるので、選択したい外観にチェックを入れます。
4. 画面上で該当フェースがハイライトされるのを確認し、「OK」をクリックして選択を確定します。（キャンセルした場合は選択状態が自動解除されます）
5. 選択されたフェースを右クリックして「選択セットを作成」したり、CAM（製造ワークスペース）でのツールパス加工面指定にそのまま活用できます。
